# csv_stat

[![tests](https://github.com/maxzeoo/csv_stat/actions/workflows/test.yml/badge.svg)](https://github.com/maxzeoo/csv_stat/actions/workflows/test.yml)
> 纯Python标准库实现的CSV文件统计命令行工具。

## 目录结构

| 文件 | 作用 |
|---|---|
| main.py | 主程序，输出数据统计摘要 |
| test_main.py | 测试程序，测试main.py各功能 |
| README.md | 程序介绍与日志 |

| scores.csv | 示例数据 |
| 对照.md  | 测试用例对照文档 |

## 项目介绍
读取CSV文件，输出数据统计摘要：
1. 统计总行数据行数
2. score列：最大值、最小值、平均值（处理空值以及使用`safe_float`处理脏数据）
3. subject分组：每组记录数量、分组平均分
4. 空值处理：空subject标记为`未标记`，跳过空score
5. 支持传入多个文件路径批量处理；捕获文件不存在、编码错误，自动跳过异常文件
6. 空间复杂度 O(k)，k为不同科目数量，流式逐行读取，具备大规模数据处理基础
7. 检测文件表头格式，规避中文逗号、表头缺失等格式问题

本项目仅使用Python内置标准库：`csv`、`sys`。

## 环境要求
- Python >=3.8
- 仅使用Python自带标准库，无需pip安装包

## csv格式要求
- 必须要有表头：`subject,score`，不然DictReader读取会出错。
- 列分隔符必须使用**英文半角逗号 `,`**；中文全角逗号`，`不会被识别为分隔符，会造成列解析失败；
- 表头字段首尾若带有空格，程序会自动清洗表头空格

## 异常处理说明
- 文件不存在：打印提示，跳过当前文件，继续处理下一个
- 文件不是 UTF-8 编码：打印提示，跳过当前文件，继续处理下一个
- 表头缺少 subject/score 字段：打印格式错误提示，跳过当前文件

## 使用方法
1. 将测试数据 `scores.csv` 放在项目根目录
2. 运行脚本
```bash
python main.py test1.csv test2.csv
```


## 测试设计

本项目附带 pytest 测试用例。
1. 本测试方案使用了等价类：分数低于0，0-100，分数高于100
2. 本测试方案使用了-1，0，99，100，101五种测例来测试边界值
3. 本测试方案在编写断言时,尝试将断言故意改错:assert '一共有5行数据' in captured.out的5改成999,最终红了一条,改回后绿了一条
4. 本测试方案针对以下几点进行测试了：
- 用户输入缺少.csv文件，是否正常退出，是否有提示话语
- 当用户输入.csv文件不存在，编码不为utf-8，内容不存在或存在错误，是否有提示语
- 当文件具有score表头但没有score数据时，是否有提示语
- 当文件score数据带空格，缺少数据，非数字类型时，能否正常清洗或跳过
- 当文件subject数据缺失时，是否标记其为：未标记
- 当某一科目正好没有一条成绩，其平均分是否标记为：缺少数据

## 已知问题
- 如果文件编码为gbk，但是未使用中文，大概率不会报错
- 在main函数中DictReader读取文件，会自动识别第一行为表头，如果无表头其实代表该文件没有内容。
- main函数具有处理多项文件的能力，但未检测多文件出错（由于本项目仅为练手小项目，在此不做多余安排）
- 使用pytest创建临时样本时,只含空白的行会被当成一行数据且数据值不会被 strip,例如    数学,则会显示科目： 数学

## 已修复
1. 将退出码覆盖了main函数中L103，L113行的三个报错，当出现报错时，退出码为1
2. 修复了BOM导致误报，将encoding由utf-8改为utf-8-sig
3. 表头检测误报为无用，现已修改
